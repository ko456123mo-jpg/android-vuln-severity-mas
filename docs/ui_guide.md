# دليل واجهة Streamlit — المرحلة 6

> 8 صفحات منفصلة + دعم عربي/إنجليزي (RTL) + تنقل حسب الدور + توثيق كامل.

## التشغيل

```bash
python scripts/run_api.py --port 8000     # الخادم أولاً (طرفية 1)
python scripts/run_ui.py  --port 8501     # الواجهة (طرفية 2)
# ثم: http://localhost:8501   — دخول: admin / admin123
```

- `MAS_API_URL` يحدد عنوان الـ API (افتراضي `http://127.0.0.1:8000`). الطلبات تخرج من
  **خادم Streamlit** لا من المتصفح — لذا localhost صحيح حتى خلف بروكسي.
- أعلام التشغيل: `--server.enableCORS=false --server.enableXsrfProtection=false
  --browser.gatherUsageStats=false` (بيئة تطوير؛ فعِّلها في النشر خلف نطاق مملوك).

```

│   ├── score_breakdown.py   Waterfall لمعادلة 0.6/0.2/0.2
│   └── diff_view.py         مقارنة side-by-side: النظام ↔ المراجع البشري
└── pages/              8 صفحات مستقلة (تُفتح من القائمة الجانبية)
```

**نمط مزدوج للجلسة**: عبر `app.py` (تنقّل `st.navigation`) يعرض الشريط مرة واحدة
ويضبط علم `_ui_sidebar_ready`؛ وعند تشغيل صفحة مستقلة (اختبار/`streamlit run pages/xx.py`)
تعرض الصفحة الشريط بنفسها — لا تكرار ولا انقطاع. كل صفحة تبدأ بـ `page_setup(...)`
التي: تضبط إعداد الصفحة، تحقن RTL، تعرض الشريط (عند اللزوم)، تفرض تسجيل الدخول،
تتحقق من دور الصفحة، وتعيد عميل API جاهزاً.

## تبديل اللغة و RTL

- المُبدِّل في الشريط الجانبي (`i18n.LANGUAGES`)، الحالة في `st.session_state["lang"]`.
- العربية ⇒ حقن CSS (`direction: rtl`) على التطبيق والشريط والجداول، مع إبقاء
  الكود/الـ snippets LTR. الإنجليزية ⇒ LTR بلا CSS.
- كل النصوص عبر `t("key")` — لا نصوص مكتوبة مباشرة في الصفحات (قاعدة المرحلة 6).
