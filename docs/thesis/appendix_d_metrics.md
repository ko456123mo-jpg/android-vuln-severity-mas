## د-1) مخزون المقاييس وربطها بأسئلة البحث

| المقياس | الدالة | السؤال | لماذا هذا المقياس |
|---|---|---|---|
| Precision / Recall / F1 | `precision_recall_f1(tp, fp, fn)` | RQ1 (كشف) | متوازن بين إسراف وارتداد الكشف |
| المتوسط الماكروي + فترة ثقة | `bootstrap_ci` على F1 | RQ1 | لا يُهيمن تطبيق كبير على المتوسط |
| نسبة الاتفاق الخام | `percent_agreement` | RQ2 | قياس مباشر سهل التفسير للإدارة |
| Weighted Cohen's κ (تربيعي) | `weighted_cohens_kappa` + `manual_quadratic_kappa` | RQ2 | اتفاق **بعد** تصحيح الاتفاق العشوائي وبوزن رتبي |
| Gwet's AC1 | `gwet_ac1` | RQ2 | بديل مستقرّ عند التفاوت الكبير في الانتشار (مفارقة κ) |
| مصفوفة الالتباس 4×4 | `confusion_matrix` | RQ2 | **كيف** يخطئ النظام: خطأ رتبي أم قفزي |
| فترات الثقة | `bootstrap_ci` (10,000/بذرة 42) | RQ1·RQ2 | لا يوجد افتراض توزيعي (n صغير) |
| اختبار مزدوج t + Wilcoxon + Cohen's d | `paired_test` / `cohens_d_paired` | RQ3·RQ4·RQ5 | مقارنة أوضاع على **نفس** التطبيقات |
| سلّم التفسير | `interpret_kappa` | RQ2 | تحويل رقم إلى حكم مفهوم (Landis & Koch) |
| منحنى التعلم | `evaluation/analyze_feedback.py` | RQ5 | هل يتحسّن الاتفاق مع تراكم التصحيحات؟ |

## د-2) الدقة والاستدعاء و F1

```
precision = TP / (TP + FP)        recall = TP / (TP + FN)
F1        = 2·P·R / (P + R)       (أي: 2·TP / (2·TP + FP + FN))
قسمة على صفر ⇒ القيمة 0.0 (لا استثناء) — تُعامَل «لا نتائج» بنتيجة صفر لا انهيار
```

**مثال مُشغَّل فعلياً:** `precision_recall_f1(4, 2, 1)` →
`precision = 0.6667` · `recall = 0.8` · `f1 = 0.7273` (مخرَج الدالة نفسه، مدوَّر 4 خانات).

**المتوسط الماكروي:** `F1_macro = (1/A)·Σ_a F1_a` على مستوى التطبيق (كل تطبيق
وحدة قياس، ويُعطى وزناً متساوياً). مثال منفَّذ على ثلاث قيم
`[0.7273, 0.6667, 0.5714]` ⇒ **F1_macro = 0.6551**، وفترة الثقة 95%:
**[0.5714, 0.7273]** (10,000 إعادة، بذرة 42).

> دقّة المقارنة: الدوال تُدَوّر إلى 4 خانات ⇒ أي تحقق في الاختبارات يستخدم
> `pytest.approx(..., abs=1e-4)` بدل مقارنة تامة (قرار اختبار موثّق).

## د-3) نسبة الاتفاق الخام

```
P_o = عدد المتطابقات / n
```

**مثال:** من 10 أزواج (جدول د-7) → `P_o = 0.7`. مقياس شفّاف لكنه **لا يصحّح
العشوائية**، ولذلك لا يُنشر وحده أبداً في هذا المشروع.

## د-4) Weighted Cohen's κ بأوزان تربيعية

**الصيغة** (كما في `manual_quadratic_kappa`):

```
κ_w = 1 − ( Σ_ij w_ij·O_ij ) / ( Σ_ij w_ij·E_ij )

w_ij = (i − j)² / (K − 1)²            ← أوزان تربيعية (K = عدد الفئات = 4)
O_ij = مصفوفة المواجهة الملاحَظة     E_ij = الصفوف×الأعمدة / n  (اتفاق متوقّع)
الترتيب المفروض:  Low < Medium < High < Critical   (i, j فهارس ترتيبية 0..3)
```

**لماذا تربيعية لا خطية؟** الفئات ترتيبية والانتقال فئة واحدة أخف من قفزة فئتين؛
الأوزان `0/1/4/9` تجعل الخطأ الجسيم أغلى من الخطأ الحاشي — وهو ما يعنيه «الخطورة»
أصلاً. (البديل الخطي `0/⅓/⅔/1` رُفض: يبخّس أخطاء الحرف الواحد ولا يميّز خطأ
Medium→Critical عن Medium→High بالفرق الذي يستحقه.)

**التحقق المزدوج:** التنفيذ الأساسي عبر `sklearn.metrics.cohen_kappa_score`
والتنفيذ اليدوي بجانبه، مع اختبار يثبّت التطابق:
لنفس المدخلات ⇒ **0.8235 = 0.8235** (مقارنة فعليّة). أي انحراف بين التنفيذين
= فشل اختبار لا اختلاف رأي.

**الحالة المنحلّة (0/0):** إذا كان أحد المتقيّمين ثابتاً (لا تباين)، يعيد sklearn
`NaN`؛ الاصطلاح المُنفَّذ: التحوّل إلى الحساب اليدوي، ثم **تطابق تام ⇒ κ = 1،
وإلا κ = 0**. مثال مُشغَّل: `["High"]×5` مقابل `[High,High,High,Medium,Low]` ⇒
**κ = 0.0** (لا `NaN` في التقارير). اكتُشفت هذه الحالة عملياً في المرحلة 7 وليست افتراضاً.

## د-5) Gwet's AC1

**الصيغة** (Gwet 2008 — كما في `gwet_ac1`):

```
AC1 = (P_o − P_e) / (1 − P_e)
P_e = [ Σ_k π_k (1 − π_k) ] / (q − 1)      π_k = (تقييمات الفئة k لدى المتقيّمَين) / 2n
q = عدد الفئات
```

**لماذا بجانب κ؟** مفارقة κ الشهيرة: مع انتشار غير متوازن (مثلاً معظم الثغرات
`High`) ينهار κ رغم اتفاق عملي مرتفع. AC1 يستخدم احتمال اتفاق «غير العرضي»
بمنطق مختلف فيبقى قابلاً للتفسير. **لا يُختار الأفضل بعد رؤية النتيجة** — يُنشر
الاثنان معاً مع مجالات اختلافهما (قرار منهجي مسبق).

**مثال مُشغَّل:** لنفس أزواج د-7: `AC1 = 0.6078` مقابل `κ = 0.8235` — الفرق
نفسه هو المعلومة: κ «يعاقب» عدم التوازن أكثر، وAC1 أقرب للاتفاق الخام (0.7).

## د-6) مصفوفة الالتباس

الصفوف = خطورة النظام، الأعمدة = خطورة الخبير، الترتيب `Low → Critical`.
**مثال مُشغَّل** على أزواج د-7:

| النظام \ الخبير | Low | Medium | High | Critical |
|---|---|---|---|---|
| **Low** | 1 | 1 | 0 | 0 |
| **Medium** | 0 | 3 | 0 | 0 |
| **High** | 0 | 1 | 2 | 0 |
| **Critical** | 0 | 0 | 1 | 1 |

قراءة الجدول: جميع الأخطاء **رتبية بمسافة فئة واحدة أو اثنتين**، ولا خطأ قطبي
(لا Low مقابل Critical) — وهذا يفسّر `κ` المرتفع نسبياً مع `P_o = 0.7`.

## د-7) فترات الثقة بالبووتستراب

```
لكل تكرار b ∈ [1, 10,000]:
    عيّنة = n عنصراً بالسحب مع الإرجاع   (numpy default_rng(seed=42))
    θ_b = metric(عيّنة)
CI95 = [quantile(θ, 0.025), quantile(θ, 0.975)]        ← percentile method
```

- بذرة **42** ثابتة ⇒ الفترة نفسها حرفياً في كل تشغيل (قابلية إعادة إنتاج).
- حماية: `n_iterations < 100` ⇒ `ValueError` (عيّنة بوتستراب صغيرة = رقم مضلّل).
- يُطبَّق على أي مقياس دالّي (F1 الماكروي، κ، AC1…) بتمرير دالة المقياس.
- **نُشر مثال مُشغَّل:** F1 الماكروي 0.6551 وفترته `[0.5714, 0.7273]` — عرض الفترة
  إلزامي مع أي متوسط ماكروي في التقرير النهائي.

## د-8) سلّم التفسير (Landis & Koch)

| المدى | التسمية العربية | الملاحظة المنهجية |
|---|---|---|
| `< 0.20` | ضعيف جداً | لا يُقبل كأساس نشر |
| `0.20 – 0.40` | ضعيف | — |
| `0.40 – 0.60` | متوسط | حدّ أدنى للنقاش العلمي |
| `0.60 – 0.80` | جيد | المدى المتوقّع لنظام آلي بمراجعة بشرية |
| `≥ 0.80` | ممتاز | يحتاج تحقّقاً مستقلاً قبل الادّعاء |

## د-9) الاختبار المزدوج وحجم الأثر (A/B — RQ5)

```
diff_i = b_i − a_i
t  : paired t-test على الفروق           (scipy.stats.ttest_rel)
W  : Wilcoxon signed-rank (لا افتراض توزيع طبيعي)
d  : Cohen's d المزدوج = mean(diff) / sd(diff)      sd بدرجات حرية n−1
```

- **سياسة الفروق الصفرية:** إن كانت كل الفروق أصفاراً (تطابق تام بين الوضعين)
  فـ Wilcoxon غير معرّف؛ الاصطلاح المُنفَّذ: `stat = 0.0`, `p = 1.0` + `note`
  يشرح ذلك — لا استثناء يُسقط التحليل.
- `n < 2` ⇒ تُعاد حقول فارغة مع ملاحظة، لا تلفيق أرقام.
- **شرط التشغيل:** ≥ **20 تصحيحاً** بشرياً، وإلا يطبع `analyze_feedback.py`
  «بيانات غير كافية» بدل تحليل بلا قوة إحصائية (قرار P7-12).

## د-10) جدول اختيار المقياس (لماذا لا الآخر؟)

| الموضع | اخترنا | رفضنا | السبب |
|---|---|---|---|
| اتفاق الفئات الترتيبية | Weighted κ (تربيعي) | κ غير موزون | الفئات ليست اسمية؛ والخطأ الرتبي أخف |
| + مقياس مساند | Gwet AC1 | κ وحده | مفارقة الانتشار غير المتوازن |
| فترات الثقة | بوتستراب (10k) | CI معياري (z/t) | n صغير ولا افتراض توزيعي |
| مقارنة الأوضاع | t + Wilcoxon + d | t فقط | حجم عيّنة صغير + إفصاح عن حجم الأثر |
| المقارنة بين أدوات AI ومراجعة آلية | κ للفئات + تصنيف الخطأ بالمصفوفة | ضرب `+1/−1` كدقة | الدقة الخام تخفي نوع الخطأ واتجاهه |

## د-11) مثال الملحق التعليمي (كامل، مُشغَّل)

**البيانات (10 أزواج):**

| # | النظام | الخبير |
|---|---|---|
| 1 | Critical | Critical |
| 2 | High | High |
| 3 | High | **Medium** |
| 4 | Medium | Medium |
| 5 | Low | Low |
| 6 | Critical | **High** |
| 7 | Medium | Medium |
| 8 | High | High |
| 9 | Low | **Medium** |
| 10 | Medium | Medium |

**النتائج (من تشغيل الدوال نفسها):**

| المقياس | القيمة |
|---|---|
| نسبة الاتفاق الخام | **0.7** |
| Weighted κ (sklearn) | **0.8235** |
| Weighted κ (يدوي) | **0.8235** (تطابق) |
| Gwet AC1 | **0.6078** |
| تفسير κ | «ممتاز»؟ لا — `0.8235 ≥ 0.80` ⇒ «ممتاز» بحسب السلّم، ويُلزم هذا تحقّقاً مستقلاً قبل أي ادّعاء |

**تحقّق يدوي جزئي (κ):** الأخطاء: `High→Medium` (w=1), `Critical→High` (w=1),
`Low→Medium` (w=1) ⇒ `ΣW∘O = 3/9 = 0.3333`. والاتفاق المتوقّع لكل خلية يُحسب من
حوافّ الجدول (مثال الخلية Critical/Critical: `(2×2)/10 = 0.4` بوزن صفر؛ والخلية
Low/Medium: حوافّ `2×4` بوزن 1…) فينتج `ΣW∘E ≈ 1.8889` ⇒
`κ = 1 − 0.3333/1.8889 = 0.8235` ✓ يطابق التنفيذ. (هذه هي الفائدة التعليمية:
الرقم يُعاد اشتقاقه بالقلم، لا يُقبل كصندوق أسود.)
